## Featured project — AEGIS

**AI Evidence-Grounded Intelligence System**

AEGIS investigates synthetic technical incidents through a bounded, sequential LangGraph workflow combining document retrieval, read-only SQLite analysis, configurable synthesis providers, and deterministic citation verification.

**Repository:** [RAG-AI-Evidence-Grounded-Intelligence-System](https://github.com/itsmyfacade/RAG-AI-Evidence-Grounded-Intelligence-System)

**Live demo:** [aegis-ai-y41k.onrender.com/demo](https://aegis-ai-y41k.onrender.com/demo/)

The hosted demo uses deterministic local synthesis and lightweight lexical retrieval. The full local configuration supports Chroma with Sentence Transformers, and the application includes an explicitly selected AWS Bedrock / Amazon Nova Micro provider. These modes are not interchangeable: the hosted demo does not run Bedrock or semantic vector retrieval.
