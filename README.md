## Featured projects

### Sentiment Lab

A full-stack natural language processing workbench using real DistilBERT inference through a Flask API and Next.js interface. It supports positive and negative classification, confidence scores, single and batch analysis, session history, and CSV export.

- [Live demo](https://sentiment-lab-web.onrender.com)
- [Source repository](https://github.com/itsmyfacade/sentiment-app)
- Stack: Python, Flask, PyTorch, Hugging Face Transformers, Next.js, TypeScript, Docker, Render, GitHub Actions

### Semantic Discovery

An embedding-based product discovery application using the all-MiniLM-L6-v2 model, normalized 384-dimensional vectors, and cosine similarity. It supports semantic search, query comparison, catalog exploration, category and text filtering, and CSV export over 80 synthetic demonstration records.

- [Live demo](https://semantic-discovery-web.onrender.com)
- [Source repository](https://github.com/itsmyfacade/recommender-app)
- Stack: Python, Flask, Sentence Transformers, MiniLM, Next.js, TypeScript, Docker, Render, GitHub Actions
- Evaluation: Recall@5 0.6833 and MRR 1.0000 across five representative synthetic queries. These results are limited catalog evaluation, not production recommendation accuracy.

### AEGIS

An evidence-grounded intelligence application that combines bounded LangGraph workflows, retrieval, read-only SQL analysis, structured synthesis, and citation verification over synthetic investigation data.

- [Source repository](https://github.com/itsmyfacade/RAG-AI-Evidence-Grounded-Intelligence-System)
- [Hosted demonstration](https://aegis-ai-y41k.onrender.com/demo/)
- Stack: Python, FastAPI, LangGraph, LangChain, SQLite, retrieval workflows, AWS Bedrock integration, Docker, GitHub Actions
